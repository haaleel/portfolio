# Haleeludheen N — Portfolio

A one-page site for a full-stack software engineer in Kochi: skills, Global Infonet experience, CMS AI chat integration, and a personal B2B marketplace built solo.

Personal details and project copy live in [`content/site.ts`](content/site.ts).

## Run it locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Put it on GitHub and Vercel

1. Create a new repository on GitHub and push this project to it.
2. On [vercel.com](https://vercel.com), choose **Add New → Project**.
3. Import that GitHub repository.
4. Leave the framework as Next.js and deploy.

Vercel gives you a public link. Later deploys happen when you push to GitHub.
